# סנכרון עם Google Drive: הגדרה חד־פעמית

המתכונים, האפייה הפעילה, הסטארטר וההיסטוריה נשמרים בקובץ JSON אחד בתיקייה **נסתרת של האפליקציה** ב-Google Drive (הרשאת `drive.appdata`). האפליקציה לא רואה ולא נוגעת באף קובץ אחר שלך, ואתה לא רואה את התיקייה הזו ב-Drive הרגיל.

## איך זה עובד
- **אופליין קודם:** הכול נשמר מקומית ועובד בלי רשת. שינויים נרשמים בתור, והסנכרון קורה לבד כשחוזרת רשת, כשפותחים את האפליקציה, ובניסיונות חוזרים (המתנה גדלה: 15 שניות עד 15 דקות). במסך "סנכרון" רואים: מסונכרן, ממתין, אין רשת או שגיאה.
- **התנגשויות:** כל פריט (מתכון, אפייה פעילה…) נבדק לבד. אם שונה רק במקום אחד, הגרסה המעודכנת מנצחת. אם שונה בשני המקומות, הגרסה החדשה יותר מנצחת והישנה נשמרת כמתכון בשם "(עותק מסנכרון)". מחיקה לעולם לא מוחקת פריט שנערך במקום אחר.
- **תמונות:** בשלב הזה נשארות מקומיות במכשיר (עוד אין תמונות באפליקציה). כשיתווספו, יסונכרנו הנתונים והתמונות הקטנות.
- **אנדרואיד:** גוגל חוסמת התחברות בתוך WebView רגיל, לכן באפליקציית האנדרואיד ההתחברות תבוא מהצד הנייטיבי (`window.SourdoughAuth`). עד שזה ייבנה, הסנכרון עובד באתר (PWA) כולל PWA מותקן בכרום.

## מה צריך לעשות (4 דברים, פעם אחת)
1. נכנסים ל-https://console.cloud.google.com ויוצרים פרויקט חדש (למשל "Sourdough").
2. **APIs & Services ← Library** ← מחפשים **Google Drive API** ← **Enable**.
3. **APIs & Services ← OAuth consent screen**: סוג External, שם אפליקציה "מחמצת לעד", המייל שלך. ב-Scopes מוסיפים `.../auth/drive.appdata`. ב-**Test users** מוסיפים את כתובת ה-Gmail שלך (כל עוד האפליקציה במצב Testing אין צורך באימות גוגל).
4. **APIs & Services ← Credentials ← Create credentials ← OAuth client ID** ← סוג **Web application** ← ב-**Authorized JavaScript origins** מוסיפים `https://alon24.github.io` (ולבדיקות מקומיות גם `http://localhost:4173`) ← Create. מעתיקים את ה-**Client ID** (נראה כמו `123-abc.apps.googleusercontent.com`).

אחר כך ב-GitHub: **Settings ← Secrets and variables ← Actions ← לשונית Variables ← New repository variable**, שם: `GOOGLE_CLIENT_ID`, ערך: ה-Client ID. (זה **Variable** ולא Secret: מזהה כזה גלוי מטבעו. לא צריך להדביק שום סוד בשום מקום.) מריצים מחדש את ה-workflow "Deploy app to GitHub Pages" (או כל מיזוג חדש ל-main).

בסוף: באפליקציה ← בית ← "סנכרון עם Google Drive" ← "התחברות עם Google".

## חלופה אם Drive יתברר ככבד מדי
סנכרון דרך ה-Worker של בוט הטלגרם (Durable Object עם מפתח סנכרון אישי). אותו מנוע מיזוג, רק `Remote` אחר.
